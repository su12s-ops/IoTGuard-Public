#### 2. 采集节点与运行时遥测恢复

**根因**：其一，`scripts/run_docker_collection_node.py` 远端采集循环硬编码 `for _ in range(1200)` × 3 秒 ≈ 1 小时后退出，且 SSH 断开后整个脚本退出不重连——即第一阶段记录的「临时隧道约一小时失效」；其二，`backend/.env.docker` 的 `LINUXGUARD_OPENWRT_LOG_CONNECTION_IDS` 为空，周期 logread 采集从未启用，传感器心跳自然 stale。另外实验 VM（Ubuntu 采集节点宿主与 OpenWrt-Lab）当时处于关机状态。

**修改与操作**（`backend/.env.docker` 为本地部署配置、不入库，其余入库）：

| 文件 / 操作 | 用途 |

| `scripts/run_docker_collection_node.py` | 重写为会话循环：每会话重新校验钉扎主机指纹与授权身份；反向隧道 + 远端采集器；会话退出按 5→60 秒封顶退避自动重连；远端领取循环无限化且瞬时失败（HTTP 0/5xx）循环内退避重试，仅 401/403 授权拒绝退出；出站请求统一经 `fetch_json`（http/https 限定、拒绝内嵌凭据、主机须在操作员声明的本机后端白名单、拒绝重定向） |
